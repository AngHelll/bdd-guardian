# pytest-bdd-demo — Capa B (Python pytest-bdd)

Minimal [pytest-bdd](https://pytest-bdd.readthedocs.io/) workspace for manual verification of BDD Guardian `python-pytestbdd`.

## Capa B

1. Install `bdd-guardian.vsix` (Extensions → … → Install from VSIX…)
2. **File → Open Folder…** → this directory
3. Wait for status bar **Ready**
4. Open `features/search.feature`
5. Verify:
   - CodeLens shows both steps bound
   - **Go to Definition** opens `step_defs/search_steps.py`

Guardian does not run pytest.
